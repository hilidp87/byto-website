# UI Styling Skill - Summary

This comprehensive skill enables creation of beautiful, accessible user interfaces through three integrated layers:

## Core Stack

**shadcn/ui Components**: "Pre-built accessible components via Radix UI primitives" with a copy-paste distribution model and full TypeScript support.

**Tailwind CSS**: A utility-first framework providing "zero runtime overhead" styling with mobile-first responsive design and automatic dead code elimination.

**Canvas-Based Design**: Museum-quality visual compositions emphasizing "sophisticated visual communication" with minimal text and maximum visual impact.

## Key Capabilities

The skill covers form validation, responsive layouts, dark mode implementation, accessibility patterns, and complex UI patterns like data tables and command palettes. It includes component installation via CLI, theme customization through CSS variables, and keyboard navigation patterns.

## Setup

Installation begins with `npx shadcn@latest init` which configures both shadcn/ui and Tailwind. Components can then be added individually and styled using Tailwind utility classes directly in JSX.

## Best Practices

Focus on component composition, mobile-first responsive design, accessibility-first implementation, and consistent design tokens. The approach emphasizes treating UI as a craft where every detail matters.

## Resources

Official documentation at shadcn/ui.com and tailwindcss.com, plus related tools like v0.dev for AI-assisted UI generation.
