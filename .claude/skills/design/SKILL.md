# ckm:design Skill Overview

This is a comprehensive design skill built on Claude Agent SDK that unifies multiple design disciplines under one umbrella.

## Core Capabilities

The skill covers **brand identity, design tokens, UI styling, logo generation, corporate identity programs (CIP), HTML presentations, banner design, icon design, and social media imagery**. It supports 55+ logo styles, 50 CIP deliverables, 22 banner styles, and 15 icon variations.

## Key Components

**Logo Design:** Uses Gemini AI to generate logos across 55 styles, 30 color palettes, and 25 industry guides with white background outputs.

**CIP (Corporate Identity):** Produces "50+ deliverables, 20 styles, 20 industries" through mockup generation with or without custom logos.

**Slides:** Creates "strategic HTML presentations with Chart.js, design tokens, copywriting formulas" for pitch decks and presentations.

**Banner Design:** Generates designs across social media, ads, web, and print with 22 art direction styles and platform-specific dimensions.

**Icon Design:** Produces SVG icons using Gemini 3.1 Pro in 15 styles across 12 categories.

**Social Photos:** Multi-platform image design workflow converting HTML/CSS to screenshots for Instagram, Facebook, LinkedIn, Twitter, YouTube, and Pinterest.

## Architecture

The skill routes tasks to external sub-skills (brand, design-system, ui-styling) and integrates with related tools like frontend-design, ui-ux-pro-max, and chrome-devtools for visual output.
