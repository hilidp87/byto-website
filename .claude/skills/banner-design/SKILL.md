# Banner Design Skill Overview

This Claude agent skill enables creation of multi-format banners for social media, advertising, websites, and print materials.

## Core Capabilities

The system generates **multiple art direction options** per request using AI-powered visuals. It handles banner design exclusively—not video editing, full website design, or print production.

## Key Workflow Steps

**Requirement Gathering**: Collect details on purpose, platform/dimensions, content, brand guidelines, style preferences, and quantity needed.

**Research & Direction**: Activate design intelligence skills and research Pinterest for 3-5 reference pins matching the specified style and purpose.

**Design & Generation**: Create HTML/CSS banners using exact platform dimensions, then generate visual elements via AI tools (Standard model for backgrounds; Pro model for complex illustrations).

**Export**: Screenshot each banner to PNG at exact platform specifications using Chrome DevTools.

**Presentation**: Show all options side-by-side with design rationale and file information.

## Platform Reference

Common dimensions include Twitter header (1500×500px), Instagram story (1080×1920px), YouTube channel art (2560×1440px), and website hero (1920×600-1080px).

**Design standards**: "max 2 typefaces, single CTA, 4.5:1 contrast ratio" and keep critical content within 70-80% safe zones.

The skill uses MIT licensing and integrates multiple specialized AI capabilities for comprehensive creative asset generation.
