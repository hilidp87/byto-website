# UI/UX Pro Max - Design Intelligence Skill Overview

This comprehensive design skill provides guidance for creating professional user interfaces across web and mobile platforms. It contains structured recommendations covering 50+ styles, 161 color palettes, 57 font pairings, and 99 UX guidelines.

## Core Purpose

The skill activates when tasks involve "UI structure, visual design decisions, interaction patterns, or user experience quality control." It should be skipped for pure backend logic, APIs, databases, or non-visual work.

## Priority Framework (1-10)

The skill organizes requirements by impact level:

**CRITICAL priorities:**
- Accessibility standards like "Minimum 4.5:1 ratio for normal text" and keyboard navigation
- Touch targets meeting "Min size 44×44px" with proper spacing

**HIGH priorities:**
- Performance optimization including image formats and layout shift prevention
- Style consistency matched to product type
- Responsive design with mobile-first breakpoints
- Navigation patterns with predictable back behavior

**MEDIUM priorities:**
- Typography systems and color semantics
- Animation timing (150-300ms for micro-interactions)
- Form validation and feedback mechanisms

**LOW priorities:**
- Chart type selection and data visualization accessibility

## Practical Workflow

Users follow a four-step process:

1. **Analyze requirements** - Identify product type, audience, and style preferences
2. **Generate design system** - Run `--design-system` command for comprehensive recommendations
3. **Supplement searches** - Use domain-specific queries for deeper detail on specific elements
4. **Apply stack guidelines** - Reference technology-specific best practices

## Common Professional Standards

The skill emphasizes frequently-overlooked quality markers: vector icons instead of emojis, consistent stroke widths, proper contrast verification in both light and dark modes, safe-area compliance, and semantic color tokens rather than hardcoded values.

A pre-delivery checklist covers visual quality, interaction responsiveness, accessibility, layout stability across devices, and theme consistency before implementation.
