# ckm:slides Overview

**ckm:slides** is a tool for crafting strategic HTML presentations that integrates Chart.js visualizations, design tokens, responsive layouts, and copywriting best practices.

## Key Features

The tool handles "marketing presentations and pitch decks" along with "data-driven slides with Chart.js" and "strategic slide design with layout patterns." It emphasizes copywriting-optimized content creation.

## How It Works

The system uses a routing structure that:
1. Extracts the subcommand from your arguments
2. Loads the matching reference documentation
3. Executes using the remaining parameters

## Available Resources

The knowledge base includes references for layout patterns, HTML templates, copywriting formulas, and slide strategies—providing a comprehensive foundation for presentation design.

**Usage pattern:** `[topic] [slide-count]`
